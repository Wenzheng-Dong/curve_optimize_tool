# 关于 `resonant_composite_robust_x_pi_100samples_1GSa.csv` 的检测报告

2026-08-09。器件参数用 `configs/device_novera.json`（α/2π = −198.48 MHz，Ω_max/2π = 50 MHz，
T1 = 35 µs，T2echo = 41.9 µs）。

详细数据与全部扫描见 `AUDIT_resonant_composite_robust_x_pi.md`，图见 `audit_figures.png`。

---

## 结论先说

**这条脉冲的设计没错，错的是它被当成"可以直接播"的波形。**
在二能级模型里它是一个精确到 1e-15 的 X(π)；在真实的三能级 transmon 上它是
一个 **169.8° 的、转轴偏了 7° 的旋转**，门误差 **5.4e-3**。
这 5.4e-3 里 **98% 是没做 AC Stark 频率标定**，剩下的是没有 DRAG。

## 这是什么波形

标准 **BB1 复合脉冲**：π(0°) → π(104.43°) → 2π(313.42°) → π(104.43°)，
四段 raised-cosine，总面积 **5π**，100 ns，峰值 49.92 MHz（顶到 Ω_max）。
BB1 的用途是抵抗**幅度标定误差**，代价是 5 倍时长。

## 检测一：二能级纯积分

把 CSV 的 Ω_x、Ω_y 直接积分（sample-and-hold，1 ns 一格）：

- 转轴 = (1, 6e-17, −2e-14)，转角 = **180.0000°**
- 1 − F̄ vs X(π) = **−2.7e-15**（数值零）
- **最佳 virtual-Z = 0**，一点修正都不需要
- 幅度鲁棒性确实存在：ε = ±10% 时才 5.2e-6

**这一层完全没问题。所以实验偏差的原因不在波形本身。**

## 检测二：三能级 transmon 模拟

三个独立实现互相对账一致（本次 expm 链 / 项目的 `curve_opt.gate.three_level_propagator` /
QuTiP ODE：5.3857e-3 / 5.3857e-3 / 5.4203e-3）。

它实际实现的门（qubit block 极分解的酉部分）：

```
W = Rz(−98.713°) · Rx(169.810°) · Rz(−91.798°)
```

- **转角 169.81°，比 π 少 10.19°**（5.7% 的转角误差）
- 两个 Rz 的**和**（−190.5°）是纯 frame，**一个 virtual-Z 能吸收**
- 两个 Rz 的**差**（−6.91°）**任何 virtual-Z 都吸收不掉**

| | 1 − F̄ |
|---|---|
| 不加 virtual-Z | 7.79e-03 |
| 加最佳 virtual-Z（−6.91°） | **5.39e-03** |
| 末态泄漏 | 1.28e-04 |

**注意泄漏只有 1.3e-4，比总误差小 40 倍。**
问题不是"漏到 \|2⟩ 出不来"，而是 \|2⟩ 的虚过程（瞬时 P₂ 峰值到 3.2%）
在 0–1 子空间留下的相干相位与转轴畸变。

## 误差从哪来（按重要性）

**1. AC Stark 位移没有补偿 —— 占 98%**

用实验室真有的三个旋钮做最优标定：

| 旋钮 | 最优值 |
|---|---|
| 驱动频率 | **比 f₀₁ 高 4.83 MHz** |
| 驱动幅度 | **+1.42%** |
| virtual-Z | −37.65° |

标定后 1 − F̄ = **1.05e-04**（原来 5.39e-3）。

这个 4.83 MHz 就是 AC Stark 位移：Ω²/(2\|α\|) 在峰值处 = 50²/(2×198.5) = 6.3 MHz，
按包络平均正好是 5 MHz 量级。**实验室通常用弱脉冲 Ramsey 标 f₀₁，那里 Stark 位移为零；
把这条 5π/100 ns 满幅脉冲直接播出去，驱动就偏了 ~5 MHz。**

**2. 完全没有 DRAG —— 剩下的几乎全部**

加上标准 DRAG 正交分量（拟合 λ = 0.70）+ Stark 帧修正（k = −0.204）后，
1 − F̄ = **1.12e-05**。也就是说 **99.8% 的三能级误差就是这两项**。

这条脉冲每段都是恒相位实包络，Q 分量只是段间相位阶跃的产物，没有任何导数修正。
在 Ω/\|α\| = 0.25 的工作点上不加 DRAG 是不行的。

**3. IQ 相位旋向约定 —— 需要和实验方核对**

把 Q 取反（φ → −φ，实验室 IQ mixer 边带约定的经典分歧）：

| | 二能级 | 三能级 |
|---|---|---|
| 按给定符号 | −2.7e-15 | 5.39e-03 |
| 旋向取反 | −2.7e-15（**一模一样**） | **1.12e-02** |

二能级下这是精确对称，**任何二能级验证都发现不了**；三能级下 anharmonicity 定了手性，
误差**翻倍**。如果实验室约定与优化器相反，实测就是 1.1e-2。

## 已经排除的嫌疑

| 嫌疑 | 结论 |
|---|---|
| 时长歧义（100 ns vs 99 ns） | 等价 −1% 面积，二能级 2.8e-10，BB1 自己吸收掉 |
| AWG / IQ 有限带宽 | 复包络高斯平滑 σ = 1 ns 只到 8e-7，不是主因 |
| 段边界相位跳变 | 相位阶跃发生在包络 ≈ 0 处（0.3 MHz），设计上已规避 |

## 另外一个判断：这条脉冲值不值 5 倍时长

100 ns 的退相干代价是 **1.27e-3**，20 ns 只有 2.53e-4。
把"标定后相干误差 + 退相干"加起来，和同峰值功率的普通 20 ns 脉冲比：

| 幅度误差 ε | 复合 100 ns | 普通 20 ns |
|---|---|---|
| 0% | **1.38e-3** | **2.84e-4** |
| 2% | 1.48e-3 | 9.29e-4 |
| 3% | 1.61e-3 | 1.73e-3 ← 交叉 |
| 5% | 2.05e-3 | 4.31e-3 |

**只有幅度标定误差超过 ~3% 时这条 BB1 才划算。** 现代超导实验室远好于 1%，
所以在标定良好的机器上它是净亏的。

作为参照，本项目自己的 Novera X(π)（`novera_solve_summary.json`，T = 50 ns，只有它一半时长）：
arm E 相干 1 − F̄ = **3.06e-08**，泄漏 4.58e-08。

## 给实验方的三条

1. **先试最便宜的**：播这条脉冲时把驱动频率上移 ~4.8 MHz、幅度再标 +1.4%。
   如果误差从 5e-3 掉到 1e-4 量级，就确认是 Stark 标定问题。
2. **对一下 IQ 相位旋向约定**。这一条在二能级仿真里永远看不出来。
3. **加 DRAG**。不加 DRAG 的话，这条脉冲花掉的 5 倍时长买不到任何东西。
