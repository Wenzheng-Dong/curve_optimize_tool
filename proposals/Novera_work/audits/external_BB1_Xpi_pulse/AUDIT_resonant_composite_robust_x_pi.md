## 0. 波形是什么

单位约定自洽性已验证：`rabi_*_MHz` 是 Ω/2π（MHz），`envelope = hypot(x,y)` 到 7e-12 MHz，
`phase_rad = atan2(y,x)` 到 5e-13 rad。100 个样点 @ 1 GSa/s，**sample-and-hold 共 100 ns**
（这个解读被面积精确性反证：每段面积恰好是 π 的整数倍）。

这是一条教科书 **BB1 复合脉冲**，四段 raised-cosine，段内相位恒定：

| 段 | 样点 | 相位 | ∫\|Ω\|dt |
|---|---|---|---|
| 0 | 0–19 | 0° | π |
| 1 | 20–39 | 104.4315° | π |
| 2 | 40–79 | 313.4173° | 2π |
| 3 | 80–99 | 104.4315° | π |

总面积 **5π**，峰值 49.92 MHz（= Ω_max）。
（教科书 BB1 的 φ₁ = arccos(−1/4) = 104.4775°，3φ₁ = 313.4326°；这里用的是 104.4315° 与
313.4173°，二者还互不满足 3φ₁ 关系。差异极小、不影响结论，但说明这些相位是数值再优化出来的，
不是解析值。）

## 1. 二能级纯积分：**它是一个完美的 X(π)**

```
U_2 = [[ 8.6e-14+2.1e-14j,  -1.4e-16-1.0000j ],
       [ -3.3e-17-1.0000j,   8.6e-14-2.1e-14j ]]
```

- SU(2) 轴 = (1, 5.6e-17, −2.1e-14)，角 = 3.141592653… rad = **180.0000°**
- 1 − F̄ vs X(π) = **−2.7e-15（数值零）**，最佳 φ_vz = **0**
- 幅度鲁棒性（BB1 的卖点）：ε = ±2% / ±5% / ±10% → 3.5e-10 / 4.7e-8 / 5.2e-6，
  标度 ≈ ε⁶（误差幅度 ∝ ε³，正是 BB1 的阶数）
- 失谐**不**鲁棒：δz/2π = ±1 MHz → 3e-4 ~ 5e-4

**结论：在它自己的设计模型里这条脉冲没有任何问题，也不需要任何 virtual-Z 修正。**
所以实验偏差的来源不在这一层。

## 2. 三能级真机：**5.4e-3 的相干误差，不是泄漏**

三种独立实现互相对账：

| 实现 | 1−F̄（vz 最优） | φ_vz |
|---|---|---|
| 本次 expm 逐格链 | 5.3857e-03 | −6.915° |
| `curve_opt.gate.three_level_propagator`（JAX） | 5.3857e-03 | −6.915° |
| QuTiP ODE（样条插值样点） | 5.4203e-03 | −6.912° |

（前两者 max\|ΔU\| = 4.7e-15；QuTiP 的 0.6% 差别来自 sample-hold vs 样条，是真实物理差别不是 bug。）

**它实际实现的门**（qubit block 极分解的酉部分 W，重构残差 4.4e-16）：

```
W = Rz(−98.713°) · Rx(169.810°) · Rz(−91.798°)
```

拆开看：

- **转角 169.81°，比 π 少 10.19°**（相当于 5.7% 的转角误差）
- 两个 Rz 的**和** a+b = −190.51°：这部分是纯 frame，**一个 virtual-Z 能吸收**
- 两个 Rz 的**差** a−b = −6.91°：这部分**任何 virtual-Z 都吸收不掉**

对应的数字：

| | 1−F̄ |
|---|---|
| 不加 vz | 7.79e-03 |
| 加最佳 vz（−6.91°） | **5.39e-03** |
| 末态泄漏 1−tr(B†B)/2 | 1.28e-04 |

**注意泄漏只有 1.3e-4，比总误差小 40 倍。** 主凶不是"漏到 \|2⟩ 出不来"，
而是 \|2⟩ 的**虚过程**（瞬时 P₂ 峰值 3.2%，见 `audit_figures.png` 右上）
给 0–1 子空间留下的**相干相位/转轴畸变**。

## 3. 多少是可标定的？—— 98%

用实验室真有的三个旋钮（virtual-Z、驱动幅度、驱动频率）做最优标定：

| 旋钮 | 最优值 |
|---|---|
| 幅度缩放 | **+1.42%** |
| 驱动失谐 | **−4.83 MHz**（即驱动要打在 f₀₁ **之上** 4.83 MHz） |
| virtual-Z | −37.65° |

标定后 1 − F̄ = **1.05e-04**。即 5.39e-3 里 **98% 是标定偏移**。

那 −4.83 MHz 就是 **AC Stark 位移**：量级 Ω²/(2\|α\|)，峰值处 50²/(2×198.5) = 6.3 MHz，
按包络平均下来正是 5 MHz 量级。**这是最可能的实验现场故事**：
f₀₁ 通常用弱脉冲 Ramsey 标定，那里 Stark 位移为零；把这条 5π/100 ns 满幅脉冲直接播出去，
驱动就偏了 ~5 MHz，门误差立刻停在 5e-3 而不是设计的 1e-6。

## 4. 归因：99.8% 的三能级误差 = 缺失的 DRAG / Stark 帧修正

在同一条包络上加两项标准修正并拟合系数：

- 正交分量 Q(t) = −λ·Ė(t)/Δ，拟合 **λ = 0.70**
- 逐点帧失谐 δ(t) = k·E(t)²/Δ，拟合 **k = −0.204**

结果 1 − F̄ 从 5.39e-3 降到 **1.12e-05**，即 **99.8% 的三能级误差正是这两项**。

这条脉冲**完全没有 DRAG**：每段都是恒相位的实包络，Q 分量只是段间相位阶跃的产物，
没有任何 Ė 导数修正。在 α/2π = −198 MHz、Ω/2π = 50 MHz（Ω/\|α\| = 0.25）的工作点上，
不加 DRAG 是不可接受的。

## 5. 一个二能级检查永远发现不了的坑：相位旋向

把 Q 取反（等价于相位约定 φ → −φ，实验室 IQ mixer 边带/相位旋向约定的经典分歧）：

| | 二能级 | 三能级 (expm) | 三能级 (QuTiP) |
|---|---|---|---|
| 按给定符号 | −2.7e-15 | 5.386e-03 | 5.420e-03 |
| 旋向取反 | −2.7e-15（**完全相同**） | **1.119e-02** | 1.126e-02 |

二能级下 Ω_y → −Ω_y 是精确对称（σ_x 共轭），所以**任何二能级验证都看不出这个错**；
三能级下 anharmonicity 定了手性，误差**翻一倍**。
如果实验室的相位约定与这个优化器相反，实测门误差会是 1.1e-2 而不是 5.4e-3。
**这一条值得直接找实验方对一下 IQ 相位约定。**

## 7. 净账：这条复合脉冲值不值 5 倍时长？

退相干代价（全 Lindblad，T1 = 35 µs / T2echo = 41.9 µs）：100 ns 花 **1.27e-3**，
20 ns 只花 2.53e-4。

标定后的相干误差 + 退相干，对比同样峰值功率的普通 20 ns raised-cosine：

| ε | 复合 100 ns | 普通 20 ns | 赢家 |
|---|---|---|---|
| 0% | 1.05e-4 + 1.27e-3 = **1.38e-3** | 3.07e-5 + 2.53e-4 = **2.84e-4** | 20 ns（好 4.8×） |
| 1% | 1.40e-3 | 4.45e-4 | 20 ns |
| 2% | 1.48e-3 | 9.29e-4 | 20 ns |
| **3%** | 1.61e-3 | 1.73e-3 | 交叉点 |
| 5% | 2.05e-3 | 4.31e-3 | 复合 |
| 10% | 4.11e-3 | 1.63e-2 | 复合 |

**只有当幅度标定误差超过 ~3% 时，这条 BB1 才划算。** 现代超导实验室的 π 脉冲幅度
标定精度远好于 1%，所以在 ε = 0 附近它是净亏的。

加上 DRAG 之后复合脉冲才真正兑现鲁棒性：ε = ±10% 时 1.4e-4 / 5.7e-4（对比不加 DRAG 的
2.8e-3 / 1.3e-3），比 20 ns 脉冲好两个量级。

## 结论与给实验方的清单

1. **两能级层面这条脉冲是对的**：精确的 X(π)，不需要 virtual-Z。问题全在三能级。
2. **实测误差大的头号原因是 AC Stark 位移没被补偿**。让实验方在播这条脉冲时把驱动频率
   **上移 ~4.8 MHz**，并把幅度再标 **+1.4%**，误差应从 ~5e-3 掉到 ~1e-4。这是零成本验证。
3. **第二原因是没有 DRAG**。加上 λ ≈ 0.7 的导数正交分量 + Stark 帧修正后，
   相干误差到 1.1e-5，且 BB1 的幅度鲁棒性才真正生效。
4. **去对一下 IQ 相位旋向约定**。若约定相反，误差从 5.4e-3 变 1.1e-2，而这在二能级仿真里
   完全看不出来。
5. **重新评估这条脉冲的性价比**。100 ns 的退相干代价 1.27e-3 已经超过它标定后的相干误差，
   只有幅度误差 > 3% 才划算。要鲁棒性，本项目 50 ns 的 arm E/F 在同一颗芯片上量级好得多。
